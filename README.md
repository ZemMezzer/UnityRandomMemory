# Random Memory for Unity

Unity package built from [RandomMemory](https://github.com/ZemMezzer/random-memory) — an in-memory database with Roslyn Source Generator support.

## Installation

Open `Packages/manifest.json` and add the following line to the `dependencies` section:

```json
{
  "dependencies": {
    "com.tiredsiren.random_memory": "https://github.com/ZemMezzer/UnityRandomMemory.git?path=Assets/RandomMemory#x.x.x"
  }
}
```

Replace `x.x.x` with the desired version tag, e.g. `1.0.0`.

## Requirements

- Unity 2022.3+
